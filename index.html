AutoForm Demo Static · LocalStorage

Mock Website for Excel → Web Automation

Three example forms (Patients, Inventory, Contacts). Submissions are saved locally and displayed below. Supports CSV/XLSX import & CSV export. Perfect for GitHub Pages demos.

How to Use
  1. Pick a form tab below (Patients / Inventory / Contacts).
  2. Fill the fields and hit Save. Your data is kept in your browser via localStorage.
  3. Use Import CSV/XLSX to bulk add. Headers must match the field labels shown.
  4. Use Export CSV to download records. Clear removes only that tab’s data.
  5. This site is 100% static — ready for GitHub Pages. No backend required.
